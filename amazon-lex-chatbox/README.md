# Pizza Delivery Chatbot Using Amazon Lex

## Project Overview

This project is a pizza delivery chatbot created using Amazon Lex.
The chatbot understands customer requests and collects pizza order details such as pizza size, pizza type, quantity, and delivery address.

## Project Objectives

- Create a chatbot using Amazon Lex.
- Understand how intents and sample utterances work.
- Collect pizza order details using slots.
- Use confirmation and fulfillment responses.
- Test the chatbot using the Amazon Lex console.

 ## How the Chatbot Works

1. The user starts a pizza order.
2. Amazon Lex identifies the PizzaOrderIntent.
3. The chatbot asks for the pizza size.
4. The chatbot asks for the pizza type.
5. The chatbot asks for the quantity.
6. The chatbot asks for the delivery address.
7. The chatbot asks the user to confirm the order.
8. After confirmation, the chatbot provides a successful order response.

## Testing and Result

The chatbot was successfully built and tested using the Amazon Lex V2 test console.

Test input:
"I want to order a pizza"

The chatbot successfully collected:
- Pizza size
- Pizza type
- Quantity
- Delivery address

The order was confirmed successfully
